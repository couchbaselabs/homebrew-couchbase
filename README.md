# Couchbase C++ Client Homebrew Tap

Official Homebrew tap for [`couchbase-cxx-client`](https://github.com/couchbase/couchbase-cxx-client).

## Installation

```bash
brew tap couchbaselabs/homebrew-couchbase
brew install couchbase-cxx-client
```

Or install directly in a single command:

```bash
brew install couchbaselabs/couchbase/couchbase-cxx-client
```

## Precompiled Binary Bottles

Precompiled binary bottles hosted on [GitHub Container Registry (GHCR)](https://ghcr.io) are provided for fast installation without local compilation.

- **Package Container Page**: [couchbase/couchbase-cxx-client](https://github.com/couchbaselabs/homebrew-couchbase/pkgs/container/couchbase%2Fcouchbase-cxx-client)
